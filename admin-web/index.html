Security checklist

  • Admin account uses Firebase Authentication.
  • Admin UID is manually provisioned in protected admin_users.
  • Firestore rules must enforce permissions server-side.
  • Passwords must never be stored or displayed in plain text.
  • Critical edits should create an audit log and a backup before deletion.

Records

Edits write directly to Firestore after server permission checks. Deletions require confirmation. Every action should be logged by the backend/rules-supported workflow.
